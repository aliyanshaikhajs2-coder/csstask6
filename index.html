What are CSS Combinators?

CSS combinators define relationships between selectors. They help us select HTML elements based on their position in relation to other elements.

01

Descendant Combinator

.descendant-box p

A space selects all matching elements inside another element, even when they are nested at different levels.

02

Child Combinator

.child-box > p

The greater-than symbol selects only direct children of the parent. It does not select paragraphs nested inside another element.

03

Adjacent Sibling Combinator

.adjacent-title + p

The plus symbol selects the first matching sibling immediately after the specified element.

General Sibling Combinator

.general-title ~ p

The tilde symbol selects all matching siblings that appear after the specified element and share the same parent.
